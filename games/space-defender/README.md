# ORIONIS Space Defender

Phaser 3.90.0 ile oluşturulmuş bağımsız uzay savunma oyunu. Statik yayın: `static/games/space-defender/`.

Kontroller: WASD / ok tuşları hareket; Space ateş. Dokunmatik: sürükle, otomatik ateş.

Lisans: Bu oyuna ait özgün kod MIT. Phaser kendi MIT lisansı altındadır. Üçüncü taraf sanat varlığı kullanılmaz. Yayınlanan HTML Phaser'ı jsDelivr CDN'den yükler, bu yüzden çevrimdışı modda çalışmaz.
